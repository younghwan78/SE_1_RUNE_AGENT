# SoC Knowledge Seed Fixture Spec

This fixture set is the first Stage B/C validation set for the SoC Knowledge
PoC. The curated seed fixture is intentionally small, but the generated scale
fixture now reaches the Phase 1 target of 200 JIRA, 100 Confluence, and 100
Email artifacts.

- 2 projects: `SOC-N-1`, `SOC-N-2`
- curated seed: 40 artifacts, with 20 JIRA, 10 Confluence, and 10 Email
- generated scale: 400 artifacts, with 200 JIRA, 100 Confluence, and 100 Email
- generated scale query annotations: 30 queries over the 400-artifact fixture
- all V-Model levels L0-L5 covered
- all initial concerns covered at least once
- major components covered across source types
- 8+ ground-truth queries covering concern, intersection, timeline, lifecycle,
  and graceful unknown patterns

The fixture stores SoC axis ground truth under `metadata.soc_axes` so the first
classifier/eval loop can be deterministic before real data is introduced.

The scale files are generated by `ops/fixtures/generate_soc_scale_fixture.py` and
validated separately with `ops/fixtures/validate_soc_fixtures.py --coverage-mode
scale`. The generated scale query set runs through the same Stage F answer
comparison loop, while manual curation and storage-backed retrieval remain
separate follow-up work.
